# LuxUI Genesis

Premier espace de l’écosystème LuxUI : une base front‑end premium en HTML5/CSS/JS, pensée pour créer des interfaces élégantes, performantes et modulaires.

## ✨ Vision

LuxUI Genesis pose les fondations d’un design system sombre et doré, minimaliste et structuré, aligné avec l’univers de [jbatistama.com](https://jbatistama.com).
Site en ligne : [https://jbatistama.com/luxui-genesis/](https://jbatistama.com/luxui-genesis/)

## 🚀 Fonctionnalités

- HTML5 complet avec meta tags et Open Graph  
- Design premium sombre + doré (LuxUI)  
- Navigation avec menu responsive  
- Composants réutilisables (boutons, cartes, sections)  
- JavaScript vanilla minimal et lisible  
- Base idéale pour les futurs espaces “New Space”

## 📁 Structure

- `index.html` — page d’accueil LuxUI Genesis  
- `assets/css/luxui.css` — style global et design system  
- `assets/js/luxui.js` — interactions de base (menu, navigation SPA)  
- `assets/images/` — visuels (og-image, background)  
- `README.md` — guide d’utilisation  
- `TODO.md` — tâches et roadmap
